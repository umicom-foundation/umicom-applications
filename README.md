# Umicom Applications

Umicom Applications is the runnable multi-application superproject for the Umicom ecosystem.

The repository contains one pinned Umicom Framework checkout and independently versioned thin application modules.

## Repository structure

```text
umicom-applications
├── framework
└── applications
